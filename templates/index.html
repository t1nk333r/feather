Catalog Health

Read-only diagnostics: scans the live catalog and storage for known problem classes. Nothing here is repaired automatically.

Reconcile Icons

Uploads on-disk app icons that are missing from the active storage backend. Dry-run first to preview, then Apply to upload. Local icon files are never deleted or modified.

Storage Self-Test

Runs a write, read, and delete round-trip against the active storage backend for icons and IPAs, using a dedicated probe object that is always deleted afterward. A permission problem is reported as PERMISSION DENIED (403), distinct from success or a missing object.

Recent Errors

The last warnings and errors logged by this server process, in memory only. Resets on restart. Secrets are redacted before storage.

Android Repository

A third-party F-Droid repository for Android devices, built and signed by the fdroid-index sidecar. Requires the "android" Compose profile.
